# Release scope

This repository publishes the supplied native framework source, core model, preprocessing builders, training, prediction and evaluation code. Original snapshot Python scripts are copied byte-for-byte. An attributed, pinned MS-TCN++ dependency and small entry-point shims complete missing repository imports.

## Excluded

- Every model checkpoint or weight file, including `weights/yolo/e_best.pt` and `weights/yolo/i_best.pt`.
- Python bytecode/cache directories.
- Raw videos and generated feature, mask, detection, prediction and checkpoint assets.
- Authentication credentials and local environment secrets.

The `cataract1k_contract/` files are the small mapping, split and metadata files already contained in the supplied snapshot; they are not the dataset's raw videos or model features.

The source scripts retain historical absolute server defaults. Set the root and asset arguments for your environment. The original snapshot reports and release documents are retained as historical provenance; their old folder names, runtime paths and locally available checkpoint descriptions are not assertions that those paths/files are included here.

## Verification boundary

`python tools/check_release.py` checks required full model files, source hashes, Python syntax, upstream attribution and the absence of weights/generated bytecode. It does not train a model, load weights, download a dataset or verify the paper's numerical results.

External detector/segmenter and visual-encoder checkpoints must be supplied separately when executing the complete raw-video pipeline. Without these external assets this release cannot immediately run the authors' fitted models.
