# Known Audit Notes

## 1. Cataract101 visual-front-end fold purity

The historical/current Cat101 Seed-42 four-fold StageFusion reproduction reuses
the same 384D feature family generated by the split-1 A3b-v12 visual encoder.
Because A3b-v12 is phase-supervised on Cataract101, end-to-end fold purity of
the upstream visual encoder must be audited before claiming that the entire
visual-front-end + StageFusion pipeline is independently trained within every
fold.

This release preserves the existing paper reproduction exactly; it does not
silently redefine or alter those results.

## 2. SICS-155

SICS-155 features were generated by the Cat101-trained A3b-v12 checkpoint.
SICS videos were not used to train that visual checkpoint, so this is a
cross-dataset frozen visual encoder, not within-SICS train/test leakage.

## 3. SICS safeguards

The canonical corrected post-processing implementation is v3.
The final safeguarded system must be named transparently, e.g.
`GeoIG-StageFusion + safeguards`, rather than presented as raw network output.

## 4. Checkpoint reporting

Seed-42 reproduction keeps both `best.model` and `epoch-100.model`, but
canonical paper reporting should state which endpoint is evaluated for each
experiment family. Do not collapse historical canonical checkpoints and
fixed-seed controlled reruns into one seed statement.
